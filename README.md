# QG 抢购项目

个人学习研究用的「辅助抢购」工具集：CDP 真点击 + 只走页面自身的请求，主打华为商城（多槽位、内部通道、响应拦截改写），并为秀动 / 苹果预留下一个平台的位置。

> 日常入口：双击 `启动.bat`（菜单）→ 浏览器打开 http://127.0.0.1:3100/workbench
> 操作手册： [`使用说明.md`](使用说明.md) ｜ 边界与红线： [`docs/限制规则清单.md`](docs/限制规则清单.md)

## 目录导览（2026-10-08 结构重组）

| 目录 | 放什么 |
|---|---|
| `core/` | 通用核心：桥接服务（:3100）、启动器、保活守护、脱管定时器、CDP 底座 |
| `platforms/` | 平台专属代码：`huawei/`（驱动 / 采集 / 体检 / 接口 / 油猴 / 拦截 / 侦察 / 实验脚本）；`showstart/`、`apple/` 为占位 |
| `web/` | 前端页面：`workbench.html`（工作台外壳）+ `platforms/`（各平台控制台）+ `tools/`（工具页） |
| `tools/` | 运维小工具：槽位登录预检、槽位窗口重启、启动器交互测试 |
| `verify/` | 验证区：活跃回归工具在根目录；`history/` 冻结的一次性探针；`tmp/` 临时产物 |
| `docs/` | 文档：技术细节（README）、审计与提速方案、加新平台约定、多账号方案 |
| `data/grab/` | 运行数据：配置 / 槽位 / 结果 / 体检（登录态与临时产物不入库） |
| `tests/` | 单元测试（vitest） |
| `归档_旧抢购平台_2026-10-08/` | 第一代平台归档（不入库） |

## 常用命令

```bash
# 服务：双击 启动.bat / 停止服务.bat / 重启服务.bat（改 core/ 代码后必须重启）
node verify/verify-console-settings.mjs                   # 控制台面板冒烟（只读）
node tools/check-slot-logins.mjs                          # 槽位登录预检
node platforms/huawei/rush-experiment-3plans.mjs --plan   # 三方案实验演练（不改配置）
```

## 铁律（改代码前先读 `docs/限制规则清单.md`）

- **商品列表 = 唯一白名单**：清单外不开窗、不点击、不发请求；匹配失败按错误处理，不兜底。
- 下单动作必须通过页面自身代码发起；不构造、不重放请求；验证码一律转人工。
- 桥接不热加载：改 `core/` 后重启服务；子进程一律 `windowsHide: true`。
- 加新平台：见 `docs/加新平台.md`（写平台三件套 + 登记清单）。
